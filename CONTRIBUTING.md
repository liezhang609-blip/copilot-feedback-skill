# Contributing

This skill is meant to help non-expert users get better outcomes from complex AI workflows.

Good contributions include:

- Better trigger wording.
- More realistic examples.
- Stronger permission boundaries.
- More test prompts.
- Failure cases where the copilot should have intervened but did not.
- Cases where the copilot over-intervened and should have stayed quiet.

Please keep the spirit of the skill:

- Practical feedback, not scolding.
- Better results, not more ceremony.
- Same-intelligence steering, not a cheap checklist.
- Complex tasks only.
